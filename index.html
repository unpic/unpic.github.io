unPIC:How to Spin an Object: First, Get the Shape Right

Rishabh Kabra Drew A. Hudson Sjoerd van Steenkiste João Carreira Niloy J. Mitra
Paper (CVPRW 2026) PDF GitHub Code

TL;DR Given a single 2D image, unPIC reconstructs 3D objects via a shape-first hierarchical pipeline: it first predicts canonical 3D Normalized Object Coordinates (NOCS) in [0, 1]³ to establish global 3D geometry, then synthesizes appearance (RGB) conditioned on those 3D coordinates to unproject a dense 3D RGB point cloud and reconstruct a Screened Poisson 3D mesh.
